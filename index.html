Tools & Technologies

Postman, Newman, Node.js, JavaScript, JSON Data Files & newman-reporter-htmlextra

Data-driven API testing project for the Restful-Booker demo API, using Postman collections, environment variables, an external JSON data file, and Newman command-line execution. Create Student (POST), Update Student (PUT), Create Technical Skills (POST) & Create Student Address (POST)

Tools & Technologies

Postman, Newman, Node.js, JavaScript, JSON Data Files & newman-reporter-htmlextra

Data-driven API automation project for the Student Management API provided by The Testing World API. The project uses a Postman collection, environment variables, and an external JSON data file to execute the same API workflow with multiple sets of student data. Each iteration creates a student, updates the student record, adds technical skills, and creates a student address. The student ID generated during creation is reused by subsequent requests in the same iteration. Automated assertions validate HTTP status codes, response times and sizes, response data, data types, non-empty fields, and success messages.

Tools & Technologies

Postman, Newman, Node.js, JavaScript, Environment Variables & newman-reporter-htmlextra

API automation testing project for the Student Management API provided by The Testing World API. The collection was developed in Postman and executed through Newman to automate the student lifecycle. The test workflow covers retrieving, creating, updating, and deleting student records, along with creating technical skills and student address records and retrieving final student details. Automated assertions validate HTTP status codes, response times, response sizes, JSON structure, field values, data types, non-empty fields, nested response objects and arrays, and success messages.
